# La Gracia de Soltar - Para GitHub Pages

## Lo que hay en esta carpeta:
- index.html = tu libro completo con tu portada original
- manifest.json = lo que hace que Chrome muestre INSTALAR
- sw.js = lo que hace que funcione sin internet y sea instalable
- portada.jpg = tu portada original (icono de la app)

## Cómo subirlo a GitHub (5 minutos, sin código):
1. Entra a github.com y crea cuenta gratis si no tienes
2. Botón New repository -> Nombre: la-gracia-de-soltar -> Public -> Create
3. Botón Add file -> Upload files -> Sube los 4 archivos de esta carpeta
4. Ve a Settings -> Pages -> Branch: main -> Carpeta: / (root) -> Save
5. Espera 1 minuto. Tu link será: https://TU-USUARIO.github.io/la-gracia-de-soltar/

## Cómo probar el botón:
- Abre ese link EN CHROME de verdad, no en WhatsApp ni en Meta AI
- Toca el botón dorado 📲 INSTALAR EN MI CELULAR
- O en los 3 puntitos de Chrome -> Instalar aplicación / Agregar a pantalla principal
- El icono que quedará será tu portada original.
